# Веб-приложение для чтения книг и комиксов

Данный проект реализован на Java Spring. Проект всё ещё находится в разработке.



![image](https://github.com/user-attachments/assets/9575bd71-dd47-45ad-aed3-16565a01306a)

Цели работы:
1. Познакомиться c моделью MVC, ее сущностью и основными фреймворками на ее основе.
2. Разобраться с сущностями «модель», «контроллер», «представление», их функциональным
назначением.
3. Получить навыки разработки веб-приложений с использованием MVC-фреймворков, написания
модульных тестов к ним и интеграции приложений в конвейер CI / CD;
4. Получить навыки управления автоматизированным тестированием и разворачиванием
программного обеспечения, расположенного в системе Git, с помощью инструмента Travis CI.

# Проект имеет структуру MVC

В качестве технологии используется: Maven, Java, SpringBoot, postgreConnect, Lombok, PostgreSQL.

Сохранение картинок в БД реализовано следующим образом:
Изображение загружается в байтовом представление -> выгружается в отдельную директорию на устройстве -> в бд идёт путь для изображения.

1. Model

В качестве моделей существую классы Book.java и Image.java, которые связаны между собой


2. View
Написана начальная страница сайта и страница для каждого произведения

3. Service
Работают с Controller и интерфейсами Repository.

4. Repository
  Работают с базой данных определённой таблицы

5. Controller
Контроллеры для Book класса и для Image.


Вывод: В итоге был реализован ридер для комиксов с подключенной базой данных на PostgreSQL
